# house-prediction-via-linear-regression
Well , it's about predicting houses with respect to the area and the prices.
These are the constraints ie parameters I have taken in order to make this model , pretty simple but still gets a general intuition on how regression works and what kind of mathematical operations we use in this algorithm.
I used MSE(Mean Square Error) , Gradient Descent(partial derivatives wrt slope and the y-intercept) and R^2(residuals square for fitting the line).
